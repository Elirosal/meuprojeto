## 📷 Como adicionar ou corrigir imagens no projeto

Para garantir que as imagens (como a foto de perfil) apareçam corretamente no site hospedado no Netlify:
1. Certifique-se de que a imagem esteja dentro da pasta do projeto (ex: em uma pasta chamada `imagens/`).
2. No HTML, use sempre caminhos relativos: `<img src="imagens/suafoto.jpg" alt="Sua Foto">`.
3. Evite usar caminhos que comecem com `C:/Users/...`, pois eles só funcionam no seu computador local.
4. Lembre-se de que o servidor diferencia letras **Maiúsculas** de **minúsculas** no nome dos arquivos.
